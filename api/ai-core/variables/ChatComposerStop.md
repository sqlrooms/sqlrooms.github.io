# Variable: ChatComposerStop

> `const` **ChatComposerStop**: `ForwardRefExoticComponent`<[`ChatComposerStopProps`](../type-aliases/ChatComposerStopProps.md) & `RefAttributes`<`HTMLButtonElement`>>

Cancels the in-flight run on activation.

**Self-hiding:** renders `null` while idle — use Send for that
state. Never disabled: stopping is always available once a run is in
flight.
