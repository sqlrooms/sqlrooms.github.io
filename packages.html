Package Reference ​

Browse SQLRooms packages and their API documentation.

Core Packages

PackageDescription
@sqlrooms/artifactsArtifact registry, workspace tab helpers, and layout integration for dashboards, notebooks, documents, canvases, pivots, and apps.
@sqlrooms/blocksShared contracts for composable blocks designed for BlockDocuments and other block containers; @sqlrooms/documents provides the editor, persistence, and runtime.
@sqlrooms/dbDuckDB-centered orchestration layer for multi-database execution.
@sqlrooms/duckdbWebAssembly build of DuckDB plus helper hooks for query execution and data import.
@sqlrooms/duckdb-coreShared DuckDB connector contracts and core query and import utilities.
@sqlrooms/layoutState and rendering for panel-based UIs with resizable splits, tabs, docking, and responsive grid layouts.
@sqlrooms/room-shellCentral application shell and Zustand-based state manager with panel system and DuckDB integration.
@sqlrooms/room-storeCore state management utilities, RoomStore, and React context providers.
@sqlrooms/uiTailwind-powered component library and theme manager used across SQLRooms packages.

AI Packages

PackageDescription
@sqlrooms/aiNatural-language querying and AI-assisted analytics tools.
@sqlrooms/ai-coreLower-level AI slice, chat UI primitives, and tool-streaming utilities.
@sqlrooms/ai-settingsAI provider and model settings state and UI components.

Feature Packages

PackageDescription
@sqlrooms/codemirrorCodeMirror 6 editor components with SQLRooms theme integration and JSON and JavaScript editing helpers.
@sqlrooms/color-scalesColor-scale config, validation, legend models, and React legend components.
@sqlrooms/cosmosHigh-performance WebGL graph visualization with Cosmos.
@sqlrooms/data-tableInteractive data grid for SQL results with sorting and pagination.
@sqlrooms/deckDeck.gl map integration with JSON-driven map specs and DuckDB and Arrow dataset binding.
@sqlrooms/documentsMarkdown document artifacts, structured BlockDocument and Document surfaces, rich editors, document assets, and document CRDT sync.
@sqlrooms/dropzoneDrag-and-drop file uploads with type validation and progress tracking.
@sqlrooms/keplerKepler.gl integration for map-first SQLRooms analytics experiences.
@sqlrooms/monaco-editorVS Code's Monaco editor with SQL-aware autocompletion.
@sqlrooms/mosaicDeclarative charting powered by UW IDL's Mosaic library.
@sqlrooms/motherduckMotherDuck connector using the WebAssembly client.
@sqlrooms/rechartsResponsive charts built with Recharts.
@sqlrooms/schema-treeInteractive database-schema explorer.
@sqlrooms/sql-editorSQL editor with history, syntax highlighting, and result docking.
@sqlrooms/vegaVega-Lite visualization components for sophisticated interactive charts.

Experimental Packages

PackageDescription
@sqlrooms/ai-ragRetrieval-augmented generation slice for semantic search over DuckDB-backed embeddings.
@sqlrooms/app-runtimeSandboxed iframe runtime bridge for generated HTML apps and their SQLRooms hosts.
@sqlrooms/canvasReact Flow-based artifact canvas for SQL, Vega, and dataflow node DAGs.
@sqlrooms/cellsShared cells model and UI primitives used by notebook and canvas views.
@sqlrooms/crdtLoro-backed CRDT slice, persistence, and sync helpers.
@sqlrooms/db-settingsDatabase connection settings state and UI components.
@sqlrooms/discussThreaded discussion system with anchor links to data points.
@sqlrooms/duckdb-nodeNode.js DuckDB connector primarily intended for automated testing and server-side SQLRooms runtimes; requires DuckDB's nanoarrow community extension.
@sqlrooms/notebookArtifact-scoped notebook UI and state slice for SQL, text, Markdown, Vega, and input cells.
@sqlrooms/pivotSlice-driven pivot table UI backed by DuckDB SQL and Vega-Lite charts.
@sqlrooms/pythonPython runtime, Pyodide adapter, commands, and block primitives for SQLRooms block documents.
@sqlrooms/s3-browserS3-compatible storage browser with uploads and directory management.
@sqlrooms/webcontainerWebContainer state slice and runtime helpers for app-building workflows.

Utility Packages

PackageDescription
@sqlrooms/utilsShared helper functions for colors, formatting, random IDs, and string utilities.
